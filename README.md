# 🚀 Curso de React - Udemy (Daniel Tapias)

Bem-vindo ao meu repositório de estudos do curso de React do instrutor **Daniel Tapias**. Aqui estou documentando minha jornada de aprendizado, projetos práticos e evolução no ecossistema front-end moderno.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

O curso aborda as tecnologias mais atuais e demandadas pelo mercado:

* **React** (Componentes, Hooks, Estado, Props, Ciclo de Vida)
* **Vite** (Empacotador ultrarrápido para desenvolvimento)
* **React Router** (Navegação e rotas dinâmicas)
* **Consumo de APIs** (Fetch API, Axios, requisições HTTP assíncronas)
* **CSS Modules** (Estilização modular e escopada por componente)
* **JavaScript Moderno (ES6+)**
